  【プロ仕様】魔王城完全ステージ 統合自動生成パック

クオリティ、デザイン、ギミックを大幅にパワーアップさせた完全版パックです。

【追加・強化されたポイント】
1. テクスチャ＆デザインの昇華:
   - 16x16 / 32x32 / 64x64 の高精細ドット絵デザイン
   - 重厚なレンガタイル、シアン色に眩しく光る時空の水晶トゲ罠
   - 甲冑をまとった「ナイトスライム（ザコ）」と時空の眼光を持つ「魔王（ボス）」

   - 時間逆行（isTimeReversed = true）で足場が逆方向に移動。

3. 広大なステージ構成（60 × 14 マス）:
   - 序盤：跳躍エリアとトゲ＆時間移動床アスレチック
   - 中盤：２段構造の廊下と複数体の警備魔物
   - 終盤：松明が灯る巨大な「魔王の間ホール」でのボスバトル

【使用手順】
1. 解凍してできた `Assets` フォルダを、Unityプロジェクトの `Assets` フォルダにドラッグ＆ドロップします。
2. Unityエディタの上部メニューより以下をクリックします：
   [ Tools ] -> [ 【高品質版】魔王城ステージ一式を完全自動生成 ]
3. `Assets/DemonCastlePackPro/Prefabs/` 内に生成される：
   `DemonCastleStage_FullLayout.prefab`
   をシーンに配置するだけで、完成された魔王城ステージが丸ごと読み込まれます！
